# Leisure illustrations

The `leisure-*.jpg` files are generated atmosphere illustrations for the A’MORE Collection demonstration site. They are not documentary photographs of the property. The leisure overview and detail pages identify them as illustrations.

The collection includes family cycling, children’s activities and zoo, fishing, garden greenhouses, an events pavilion, barbecue areas, winter tubing, skating and buggy rides.

The five `leisure-blend-*.jpg` images were generated for the approved balanced layout on 16 October 2026. All images are served locally; no third-party image requests are required.
